# 视力中心蓝牙数据汇聚系统 - UI 原型设计文档

**项目名称**: 视力中心蓝牙数据汇聚系统<br>
**设计日期**: 2026-05-23<br>
**设计版本**: v1.0<br>
**设计风格**: 医疗科技风格 (Medical Tech)

---

## 1. 设计概述

### 1.1 设计目标

- ✅ **专业性**: 符合医疗场景的视觉语言
- ✅ **可用性**: 高信息密度 + 清晰的信息层级
- ✅ **独特性**: 避免通用"AI风格"（Inter字体、紫色渐变）
- ✅ **精确性**: 仿真 56mm 热敏纸打印效果

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **精密** | 基于 8px 间距系统，精确到 1px |
| **一致** | 统一的配色、字体、阴影、圆角 |
| **反馈** | 所有交互都有视觉反馈（悬停、点击、加载） |
| **性能** | 使用 GPU 加速动画（`transform`, `opacity`） |

## 3. 页面设计

### 3.1 主界面 (`index.html`)

**功能**: 数据总览 + 设备状态 + 打印队列

**布局结构**:
```
┌────────────────────────────────────┐
│  顶部导航栏 (56px)                │
├────────────────────────────────────┤
│  页面标题区                          │
│  - 页面标题 + 副标题                      │
│  - 操作按钮（导出、刷新）                         │
├────────────────────────────────────┤
│  统计卡片区 (4列)                            │
│  [今日检查] [已完成打印] [待打印] [在线设备]          │
├────────────────────────────────────┤
│  内容网格 (2列)                      │
│  ┌──────────┐ ┌──────────────┐    │
│  │ 设备状态  │ │ 打印队列        │    │
│  └──────────┘ └──────────────┘    │
├────────────────────────────────────┤
│  最近检查记录 (表格)                            │
└────────────────────────────────────┘
```

**设计亮点**:
1. **统计卡片**: 使用左色条 (accent-color) 悬停揭示
2. **数字动画**: 页面进入时统计数字从 0 滚动到目标值
3. **设备状态**: 使用脉冲动画 (pulse) 表示在线状态
4. **打印队列**: 复选框交互，实时更新徽章数量
5. **涟漪效果**: 所有按钮点击时的 Material Design 风格反馈

## 4. 交互设计

### 4.1 动画系统

| 动画 | 用途 | 时长 | 缓动函数 |
|------|----------|----------|----------|
| `fadeIn` | 页面进入、卡片出现 | 300ms | `ease-out` |
| `slideIn` | Toast 滑入 | 300ms | `ease-out` |
| `spin` | 加载指示器 | 1000ms | `linear` (无限循环) |
| `pulse` | 在线状态指示 | 2000ms | `ease-in-out` (无限循环) |
| `ripple` | 按钮点击反馈 | 600ms | `ease-out` |

### 4.2 反馈机制

**按钮反馈**:
1. 悬停: 背景色变化 + 轻微上移 (`translateY(-1px)`)
2. 点击: 涟漪效果 (ripple)
3. 加载: 替换为加载动画 + 禁用点击

**卡片反馈**:
1. 悬停: 阴影增强 + 轻微上移 + 左色条显示
2. 点击: 背景色变化

**表单反馈**:
1. 聚焦: 边框变色 + 阴影增强
2. 错误: 边框变红 + 错误提示文字

## 5. 技术实现

### 5.1 CSS 架构

**CSS 变量管理**:
- 设计令牌（Design Tokens）集中在 `:root` 中定义
- 便于全局主题切换（未来可添加深色模式）

**BEM 命名规范**:
```css
/* Block */
.device-card { }

/* Element */
.device-card__header { }
.device-card__body { }

/* Modifier */
.device-card--connected { }
.device-card--warning { }
.device-card--disconnected { }
```

**实际代码使用驼峰命名** (更适合 JavaScript 操作)

### 5.2 JavaScript 架构

**模块化组织**:
- `app.js`: 主界面交互逻辑
- `devices.js`: 设备管理交互逻辑

**关键功能**:
1. **导航交互**: 菜单切换 + 页面切换（演示用）
2. **复选框交互**: 打印队列选择 + 徽章更新
3. **悬停效果增强**: 设备项悬停显示操作按钮
4. **统计卡片动画**: 数字从 0 滚动到目标值
5. **按钮点击反馈**: 涟漪效果 (ripple)
6. **模拟数据刷新**: 点击刷新按钮模拟加载

### 5.3 性能优化

**CSS 性能**:
- 使用 `transform` 和 `opacity` 实现动画（GPU 加速）
- 避免触发 `layout`/`paint` 的属性（如 `width`, `height`）
- 使用 `will-change` 提示浏览器优化

**JavaScript 性能**:
- 使用 `IntersectionObserver` 延迟加载动画
- 使用事件委托 (event delegation) 处理动态元素
- 避免使用 `innerHTML`（改用 `textContent` 或 `createElement`）

## 7. 可访问性 (Accessibility)

### 7.1 对比度

所有文字与背景的对比度均符合 **WCAG 2.1 AA 标准**:
- 正常文字: 4.5:1
- 大文字 (≥18px): 3:1
- 图形元素: 3:1

### 7.2 键盘导航

- 所有交互元素支持 `Tab` 键聚焦
- 按钮支持 `Enter`/`Space` 键激活
- 提供 `:focus-visible` 样式

### 7.3 屏幕阅读器

- 使用语义化 HTML (`<header>`, `<main>`, `<nav>`, `<button>`)
- 为图标按钮添加 `title` 属性
- 为装饰性图标添加 `aria-hidden="true"`

## 8. 未来扩展

### 8.1 深色模式

**实现方案**:
1. 在 `:root` 定义浅色变量
2. 在 `[data-theme="dark"]` 定义深色变量
3. 使用 JavaScript 切换 `data-theme` 属性

**配色调整**:
- 背景: `#ffffff` → `#1a1a1a`
- 文字: `#202124` → `#e8eaed`
- 边框: `#e8eaed` → `#3c4043`

### 8.2 主题定制

**实现方案**:
1. 允许用户选择主题色（蓝、绿、紫、橙）
2. 动态修改 `--primary` 变量

### 8.3 动画偏好

**实现方案**:
1. 检测 `prefers-reduced-motion` 媒体查询
2. 禁用非必要的动画

```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```
