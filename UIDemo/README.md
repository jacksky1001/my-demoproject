## 🎨 设计系统

### 配色方案 (Color Palette)

| 角色 | 色值 | 用途 | 心理暗示 |
|-----|------|------|----------|
| **主色** | `#1a73e8` | 主按钮、链接、激活状态 | 专业、可信 |
| **成功** | `#34a853` | 在线状态、成功提示 | 安全、正常 |
| **警告** | `#f9ab00` | 信号弱、待处理 | 注意、谨慎 |
| **危险** | `#d93025` | 离线状态、错误 | 紧急、警示 |
| **紫色** | `#8430ce` | 装饰性强调 | 科技、创新 |

**中性色系**: 使用 Google Material 风格的灰度体系 (`--gray-50` 到 `--gray-900`)

### 字体系统 (Typography)

| 用途 | 字体栈 | 理由 |
|------|--------|------|
| 正文 | `Noto Sans SC` | 优化中文显示，医疗场景可读性 |
| 代码/数据 | `JetBrains Mono` | 等宽字体，数据对齐美观 |

### 间距系统 (Spacing)

基于 **8px 基准** 的间距系统:
- `--space-1`: 4px (最小间距)
- `--space-2`: 8px (基础间距)
- `--space-4`: 16px (组件内边距)
- `--space-6`: 24px (组件间距)
- `--space-8`: 32px (区块间距)

### 阴影系统 (Shadows)

| 层级 | 阴影值 | 用途 |
|------|--------|------|
| `xs` | `0 1px 2px` | 分割线、小元素 |
| `sm` | `0 1px 3px` | 悬浮元素 |
| `md` | `0 2px 6px` | 卡片悬停 |
| `lg` | `0 4px 12px` | 模态框、下拉菜单 |

## 📱 页面说明

### 1. 主界面 (`index.html`)

**功能**: 数据总览 + 设备状态 + 打印队列

**设计亮点**:
- ✅ **统计卡片**: 使用左色条 (accent-color) 悬停揭示
- ✅ **数字动画**: 页面进入时统计数字从 0 滚动到目标值
- ✅ **设备状态**: 使用脉冲动画 (pulse) 表示在线状态
- ✅ **打印队列**: 复选框交互，实时更新徽章数量
- ✅ **涟漪效果**: 所有按钮点击时的 Material Design 风格反馈

**关键交互**:
- 导航菜单切换（总览、设备、队列、历史）
- 统计卡片悬停显示左色条
- 打印队列复选框联动
- 刷新按钮加载动画

---

### 2. 设备管理页面 (`devices.html`)

**功能**: 添加/编辑/测试/删除设备

**设计亮点**:
- ✅ **设备卡片**: 使用左侧彩色边框表示状态（绿=在线、橙=警告、灰=离线）
- ✅ **图标系统**: 每个设备类型有独特图标和配色
- ✅ **过滤器**: 快速筛选在线/离线设备
- ✅ **实时统计**: 顶部小型统计条，实时更新
- ✅ **添加设备向导**: 点击"添加设备"弹出模态框

**关键交互**:
- 扫描设备按钮（带旋转动画）
- 添加设备模态框
- 测试连接按钮（模拟成功/失败）
- 设备卡片悬停提升效果

---

### 3. 打印预览页面 (`preview.html`)

**功能**: 仿真 56mm 热敏纸打印效果

**设计亮点**:
- ✅ **真实尺寸**: 224px ≈ 56mm (4px/mm)
- ✅ **纸张质感**: 使用 `#fffef7` 微黄色模拟热敏纸
- ✅ **阴影效果**: 多层阴影 + inset 模拟纸张厚度
- ✅ **打印线**: 使用 `repeating-linear-gradient` 模拟打印头痕迹
- ✅ **二维码占位**: SVG 模拟二维码图案
- ✅ **响应式**: 移动端自动缩小到 200px

**关键交互**:
- 确认打印按钮（模拟打印任务发送）
- 取消按钮（带确认对话框）
- 打印样式表（`@media print`）隐藏 UI 元素

## 🔧 技术实现

### CSS 变量管理

所有设计令牌（Design Tokens）集中在 `:root` 中定义，便于全局主题切换。

### 动画性能

- 使用 `transform` 和 `opacity` 实现动画（GPU 加速）
- 避免触发 layout/paint 的属性（如 `width`, `height`）
- 使用 `will-change` 提示浏览器优化

### 响应式设计

| 断点 | 宽度 | 适配策略 |
|------|------|----------|
| 桌面端 | > 1200px | 双栏布局（设备列表 + 打印队列） |
| 平板端 | 768px - 1200px | 单栏布局，统计卡片自动换行 |
| 移动端 | < 768px | 隐藏导航菜单，全宽卡片 |

## 🚀 使用方法

### 本地预览

1. 双击打开 `index.html`（使用浏览器）
2. 点击顶部导航切换页面
3. 点击"打印"按钮查看打印预览

### 集成到 Vue 3 项目

这些原型可以直接转换为 Vue 3 组件：

```bash

├── views/
│   ├── Dashboard.vue    # 对应 index.html
│   ├── Devices.vue      # 对应 devices.html
│   ├── PrintQueue.vue  # 打印队列（index.html 部分）
│   ├── History.vue      # 历史记录

│   ├── QueueItem.vue   # 队列项目

└── styles/
    ├── variables.css     # CSS 变量（从 styles.css 提取）
    └── global.css       # 全局样式
```

## 📝 设计决策记录 (DDR)

### 为什么选择"医疗科技"风格？

1. **用户画像**: 医护人员，需要专业、可信的界面
2. **使用场景**: 医院环境，需要高对比度、清晰的信息层级
3. **差异化**: 避免通用"AI 风格"（紫色渐变、Inter 字体）

### 为什么不使用 Inter 字体？

- Inter 已被过度使用，缺乏品牌识别度
- Noto Sans SC 针对中文优化，可读性更好
- JetBrains Mono 增加"开发者工具"的感觉，符合系统定位

### 为什么打印预览要仿真 56mm 纸张？

- **用户验证**: 让医护人员在开发阶段就能看到实际打印效果
- **减少返工**: 提前发现布局问题（如文字溢出、二维码太小）
- **客户演示**: 给客户演示时更有说服力
